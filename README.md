# Medicinal Animals

Digital Humanities Storymaps project: [https://digitalhumanities.hkust.edu.hk/medicinal-animals-and-digital-storytelling-map/](https://digitalhumanities.hkust.edu.hk/medicinal-animals-and-digital-storytelling-map/).

## Components for StoryMaps

### TCM Export Flows
Visualizes geographic trade routes, flows, and connections associated with medicinal animals.

**link:** [https://hkust-dh.github.io/medicinal-animals/tcm_trade_map.html](https://hkust-dh.github.io/medicinal-animals/tcm_trade_map.html)

### TCM Animal Products Exported from Tianjin to Hong Kong
Explores temporal patterns and distributions of medicinal animal records through an interactive streamgraph.

**link:** [https://hkust-dh.github.io/medicinal-animals/tcm-hk-streamgraph.html](https://hkust-dh.github.io/medicinal-animals/tcm-hk-streamgraph.html)
